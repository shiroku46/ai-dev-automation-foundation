# Live automatic-merge probe

This deterministic documentation-only change proves that the public Foundation can validate one immutable same-repository Pull Request head, obtain independent exact-SHA review evidence, mark the Draft ready, and merge with expected-head-SHA protection.

This probe was created from the current default branch after the Queue, recovery-engine, and immutable workflow-run/job attestation repairs merged, so every trusted run is bound to the current default-branch workflow SHA and this one immutable candidate head.

It contains no Secrets, deployment behavior, production data, billing changes, repository-setting changes, paid-service configuration, or destructive operations.
